4. Assessment of the Proposed Fix
Clean R consuming 0 entropy: Effective and Minimal.
If src/sim.rs:149-155 is updated so R does not draw from self.xof when qubit == 0, stream sliding is eliminated.
Dirty R hard-rejecting before erasure: Optimal Fix.
Rather than relying on randomized phase kickback (self.phase ^= qubit & rng_val), the simulator should immediately panic or return Err if (self.qubit(op.q_target) & cond) != 0 during an R operation. This turns probabilistic detection into deterministic rejection (

Indexed Evaluator Secret & Transcript Channel Checker: Over-engineered / Redundant for Unitary Arithmetic.
Adding evaluator secrets indexed by (trial, hmr_ordinal, repetition) is standard for general quantum interactive proofs or dynamic circuits, but unnecessary here. If dirty resets deterministically reject upon non-zero qubit state, no entropy is needed for R at all.
For Hmr, static ordinal indexing leaves a minor workaround: contestants can still reorder or insert dummy Hmr instructions to permute ordinals unless an explicit dependency DAG or channel checker is enforced.
